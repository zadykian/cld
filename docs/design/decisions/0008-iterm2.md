# 8. iTerm2

Status: Accepted.

## Context

A driver for iTerm2 would run the real app on a hosted macOS runner, in levels that
[testing](../testing.md) plans. Every level beyond launching it needs permissions on the runner:
control over AppleScript or iTerm2's Python API, and Accessibility to post real key events.
Self-hosted runners are not an option for a public repository.

## Decision

iTerm2 is not automated yet. The test setup grants itself none of those permissions: that is the
maintainer's decision.

## Consequences

The terminal contract runs against tmux and JediTerm alone. What was and was not seen in iTerm2
is recorded with the status in [testing](../testing.md).
