# issue

cld's notes for the `issue` skill.

- **Title:** ``type: `cld` - description``, the type a Conventional Commits type. Name the commands
  concerned in place of `cld` where there are some:
  ``fix: `cld join`, `cld kill` - refuse a session of another repository``.
- **Length:** 150 to 350 words, as the skill says. Not the long design-document style of #26 and
  of #41.
- **Plan:** where several issues depend on each other, it gives the order they land in.
